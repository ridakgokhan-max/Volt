**Bizans'ı yıkan top**, / aslında **Bizans'ın** olabilirdi. //

1452. / **Urban** adında Macar bir top ustası / önce Bizans'a çalışmak istedi. / Ama imparator / onun küçük **maaşını** bile / düzenli **ödeyemedi**. //

Urban bu kez / genç **Sultan Mehmed'e** gitti. / Sultan, / surları yıkıp yıkamayacağını sordu. / Urban'ın cevabı tarihe geçti: / "Topumun taşları / sadece bu surları değil, / **Babil'in surlarını** bile toz eder." //

Ve yaptı. / **Sekiz metrelik** bir dev. / **Yarım tonluk** taş gülleler. / Onu taşımak için / **altmış öküz** / ve yüzlerce adam gerekti. //

Nisan 1453. / Dev top, / **bin yıldır** kimsenin yarıp geçemediği surlara / ateş açtı. //

Haliç'in ağzı / dev bir **zincirle** kapalıydı. / Mehmed de / gemilerini **karadan**, / tepelerin üstünden **yürüttü**. //

Sultan, / imparatora son bir teklif gönderdi: / **Şehri teslim et**, / canlarınız bağışlansın. / İmparator Konstantin'in cevabı: / "Şehri teslim etmek / ne **benim** elimde, / ne de burada yaşayan **hiç kimsenin**. / Hepimiz, / kendi isteğimizle **ölmeye** hazırız." //

**29 Mayıs**, / şafaktan önce son saldırı başladı. / O sabah / iki taraftan da **binlerce insan** öldü. / Anlatılana göre son imparator / surlarda **savaşarak** düştü. / Ve bin yıllık şehir / **fethedildi**. //

**Yirmi bir** yaşındaki sultan / harap imparator sarayına çıktı / ve Farsça bir beyit okudu: / "Hükümdarın sarayında / perdeyi artık **örümcek** tutuyor." //

Ve belki de hepsi, / bir imparatorun / **ödeyemediği bir maaşla** başlamıştı.
